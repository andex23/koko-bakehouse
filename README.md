# Koko Bakehouse

A mobile-first weekend delivery menu for a fictional neighbourhood bakery. Open index.html in a browser to run it locally. All assets are served from this directory.

The four menu items and naira prices are illustrative. Plain HTML and CSS render the full page. A small JavaScript enhancement lets customers include selected items in the WhatsApp draft. Customers confirm quantities and delivery details in chat.

The order link uses the requested placeholder 0800 000 0000 in Nigerian international format. Replace its number in index.html before taking real orders.

The locally hosted WebP images are resized versions of [this bakery photograph on Unsplash](https://images.unsplash.com/photo-1509440159596-0249088772ff).
