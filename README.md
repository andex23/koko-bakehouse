# Koko Bakehouse

A responsive weekend delivery menu for a fictional bakery. Open index.html in a browser to run it locally.

The page uses plain HTML and mobile-first CSS. Each menu entry in index.html contains its name, image, serving description and price. The prices are illustrative. The product and hero images are generated placeholders, compressed as WebP. The Fraunces display font is hosted locally with its license in assets.

The WhatsApp link in index.html includes a default message and works with JavaScript disabled. With JavaScript enabled, order.js adds the selected items to that message. Quantities and delivery details are confirmed in chat. Replace the Nigerian placeholder number (0800 000 0000) before taking real orders.
